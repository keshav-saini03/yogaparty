  <action>
Create `lib/geo.ts` with two exported async functions: `getDetectedCity()` and `getDetectedCountry()`. Both `await headers()` from `next/headers`. `getDetectedCity` reads `x-geo-city`, returns `null` on missing/empty, otherwise wraps `decodeURIComponent` in try/catch and returns the trimmed result (Vercel URL-encodes city names like "São Paulo" — RESEARCH Topic 2). `getDetectedCountry` reads `x-geo-country` and returns trimmed value or `null`. No client code, no `'use client'`. Per RESEARCH Pitfall 4, **always** await `headers()`.

Exact implementation per RESEARCH Topic 2 code example:

```ts
import { headers } from 'next/headers';

export async function getDetectedCity(): Promise<string | null> {
  const h = await headers();
  const raw = h.get('x-geo-city');
  if (!raw) return null;
  try {
    return decodeURIComponent(raw).trim() || null;
  } catch {
    return raw.trim() || null;
  }
}

export async function getDetectedCountry(): Promise<string | null> {
  const h = await headers();
  return h.get('x-geo-country')?.trim() || null;
}
```

Do NOT add other exports. Keep file under 30 lines.
